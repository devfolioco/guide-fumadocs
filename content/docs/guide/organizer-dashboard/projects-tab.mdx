## Projects Tab

The Projects Tab allows you to view, manage, and review all project submissions made by participants during your hackathon.

<img src="/assets/projects-tab.webp" alt="Projects Tab Overview" />

## Features

### View All Submissions

Access a comprehensive list of all projects submitted to your hackathon, including project details, team members, and submission status.

### Filter and Search

Easily filter projects by various criteria such as:
- Submission status
- Team name
- Project categories
- Submission date

### Project Details

Click on any project to view detailed information including:
- Project title and description
- Team members
- GitHub repository links
- Demo links and videos
- Technologies used
- Prize tracks applied for
