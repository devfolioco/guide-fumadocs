## How to Report a Project on Devfolio

<Video src="https://www.youtube.com/embed/ETEUWyrzVlI" title="How to report a project on Devfolio" />

## Steps to Report a Project on Devfolio

1. A project can be reported for plagiarism, recycling, or inappropriate/offensive content.

<figure>
  <img src="/assets/image (97).webp" alt="Report button on Devfolio project page" />
</figure>

2. The project builders can make their case against the report by replying to DevfolioBot’s comment on their Project Page.

<figure>
  <img src="/assets/image (129).webp" alt="Builder response to report comment" />
</figure>

3. If Devfolio’s Content & Moderation team finds the report valid, the said project will be publicly flagged on the platform.

<figure>
  <img src="/assets/image (136).webp" alt="Flagged project status" />
</figure>

4. More builders can support the builders whose project, they believe, has been flagged as a mistake by replying or upvoting/downvoting other replies.
